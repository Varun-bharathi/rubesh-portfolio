## ✨ Features & Highlights

- 🎨 **Sleek Cybernetic Aesthetic:** Tailored HSL color palette featuring deep obsidian, electric cyan (`#06b6d4`), and cyber violet accents with refined glassmorphic cards (`backdrop-filter: blur(16px)`).
- 🌓 **Dynamic Theme Switcher:** One-click instant switching between Cyber Dark mode and Clean Frost Light mode with state persistence.
- 🌌 **Interactive Constellation Canvas:** Lightweight HTML5 Canvas particle system with smooth mouse repulsion and dynamic node connectivity.
- 👤 **Portrait Spotlight Card:** High-resolution portrait frame featuring academic credentials, department standing, and direct social links.
- 🛠️ **Exact Resume Competencies Matrix:** Filterable skill matrix covering:
  - **Technical Skills:** Python, SQL
  - **Frameworks:** Pandas, Pytest, OpenCV, MediaPipe, Flask
  - **Analytical Skills:** Problem-solving, Critical thinking
  - **Soft Skills:** Communication, Teamwork, Leadership
  - **Tools:** Power BI, Figma, MS Excel, PyCharm, GitHub
- 🚀 **Featured Engineering Projects:**
  - **Facial & Hand Gesture AI-Powered Attendance System** *(OpenCV, MediaPipe, Flask, Pandas, Face-Recognition)*
  - **Real-Time Attendance & Performance Tracking with BI** *(Power BI, DAX, SQL)*
  - **Movie Ticket Reservation System** *(Python, Tkinter, PyMySQL, MySQL)*
  - **Sales Data Visualization Suite** *(Power BI, Sales Analytics)*
- 🔍 **Interactive Project Architecture Modals:** In-depth popups detailing system architectures, tech stacks, and engineering challenges overcome.
- 📜 **Dual-Mode Interactive Resume:**
  - **ATS View:** Clean, structured web resume layout with active clickable links and print-optimized styles.
  - **Original PDF View:** Embedded PDF document viewer with direct PDF download support (`Rubesh_Karthik_SS_Resume.pdf`).

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (version 18+ recommended).

Check Node and npm versions:
```bash
node -v
npm -v
```

### Installation

1. Clone or navigate to the project directory:
   ```bash
   cd "c:\Users\varun\Documents\rubesh portfolio"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development Server

Start the local Vite development server:
```bash
npm run dev
```

Open your browser and visit: **`http://localhost:5173/`**

### Production Build

Create an optimized, minified production build:
```bash
npm run build
```

Preview the production build locally:
```bash
npm run preview
```
